## ⌨️ Complete Hotkeys & Shortcuts Cheatsheet

### 🌐 Global Direct Hotkeys (Work Anywhere in Windows)

| Hotkey | Action / Feature | Description |
| :--- | :--- | :--- |
| **`Alt + Z`** | **Toggle Command Leader Mode** | Activates single-key command mode for rapid keyboard navigation. |
| **`Alt + /`** | **Print Hotkey Cheatsheet** | Generates an interactive hotkeys and voice commands directory card in chat. |
| **`Alt + I`** | **Inject Target Code** | Injects generated AI response directly into your active code editor window. |
| **`Alt + S`** | **Screen Snipe / Vision OCR** | Crops any screen region to extract code, math formulas, or questions into AI context. |
| **`Alt + W`** | **Toggle Embedded Browser** | Opens or hides the built-in stealth Chromium web browser. |
| **`Alt + B`** | **Focus Browser Address Bar** | Highlights address bar to instantly type URLs or search queries. |
| **`Alt + F`** | **Toggle Focus Mode** | Cycles overlay focus states (Normal ➔ Background Ghost ➔ Full Stealth). |
| **`Alt + P`** | **Cycle AI Model Provider** | Rotates active LLM providers (Groq Llama 3.3 ➔ Gemini 3.5 ➔ NVIDIA ➔ Web2API). |
| **`Alt + M`** | **Voice Command Center** | Toggles continuous background microphone listening for natural voice controls. |
| **`Alt + U`** | **Voice Typist Engine** | Transcribes your spoken mic speech directly into hardware typed text. |
| **`Alt + V`** | **Speaker Voice (TTS)** | Toggles text-to-speech audio narration of AI answers. |
| **`Alt + L`** | **Live Interview Mode** | Enables continuous Vision + Mic scanning for real-time technical interviews. |
| **`Alt + H`** | **Hide / Show Window** | Instantly toggles overlay visibility without closing the app. |
| **`Alt + R`** | **Reset Window Layout** | Resets window position, dimensions, and opacity to factory default defaults. |
| **`Alt + Esc`**| **Panic Emergency Hide** | Instantly hides window, silences TTS, and stops all background workers. |

## 📦 How to Download & Run Pre-Built Release (No Python Needed!)

If you want to run Invisible AI Overlay on any Windows 10 or Windows 11 PC without installing Python, Git, or dependencies:

1. **Download the Zip Archive:**
   * Download directly: [SystemAudioEngine_v10_Portable.zip](https://github.com/pmunaswamireddy/Invisible-ai/releases/download/version10/SystemAudioEngine_v10_Portable.zip) or visit [GitHub Releases](https://github.com/pmunaswamireddy/Invisible-ai/releases/tag/version10).
2. **Extract the Zip:**
   * Right-click `SystemAudioEngine_v10_Portable.zip` ➔ **Extract All...** to any folder (e.g. `C:\InvisibleAI`).
3. **Launch Immediately (< 0.5s):**
   * Double-click **`SystemAudioEngine.exe`** inside the extracted folder.
   * The overlay launches **instantly in under 0.5 seconds**!

## 🛠️ Quick Start & Build Instructions


